# Components sourced from 21st.dev

The site is plain HTML/CSS/JS with no build step, so every effect below was
hand-ported from the React / Tailwind / Framer Motion original on
[21st.dev](https://21st.dev). Behaviour, timing and easing follow the source;
colours were mapped to the Intricon palette (stone, oak, brass).

Aesthetic conventions borrowed from the registry: near-black surfaces,
`rgba(255,255,255,0.1)` hairlines, `backdrop-blur` glass pills, `rounded-2xl`
media, tight-tracking display type paired with an italic serif accent,
`tabular-nums` figures, expo-out easings (`cubic-bezier(0.16, 1, 0.3, 1)`,
`cubic-bezier(0.22, 1, 0.36, 1)`) and 20–60 ms staggers.

Fonts: [Bricolage Grotesque](https://fonts.google.com/specimen/Bricolage+Grotesque),
[Instrument Serif](https://fonts.google.com/specimen/Instrument+Serif) and
[Inter](https://fonts.google.com/specimen/Inter) via Google Fonts (SIL Open Font License).
